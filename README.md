# HelloTodo 🎀 待办小站

> Hello Kitty 风格的手机端待办提醒 PWA —— 社团活动 + 班干部任务的救星，专治"忘了这回事"。

## ✨ 功能清单

### 核心
- 📝 **输入窗口**：任务所属（自由输入+历史记录）、具体任务、DDL、重要星级（1~5 星，默认 1 星）、标签、子任务（可选）、备注（折叠成 📝 点击展开）、大事件开关、重复任务（每天/每周/每月）
- ⭐ **自动排序**：重要星级从高到低，同级按 DDL 从近到远
- ⏰ **DDL 智能变色**：`>48h 绿` → `24~48h 黄` → `6~24h 橙` → `<6h 红+卡片脉动`；剩余 < 6 小时显示**实时跳秒倒计时**
- 📊 **进度条**：表示距离 DDL 还剩多少时间，随时变色
- ✅ **勾选完成**：蝴蝶结弹出 + 星星爱心四散 + 对勾一笔画成 + 音效 + 震动的 Hello Kitty 特效；完成后进"已完成"栏，存 3 天自动消失
- 🪦 **已过期栏**：过期任务独立一栏 + 待办列表底部墓碑占位；过期 7 天未勾自动进回收站
- 📅 **DDL 日历**：月历 + 当日时间轴，同一天多个 DDL 按时段排列，时间重叠（30 分钟内）红色冲突警示
- 🎉 **大事件倒计时专区**：置顶大号倒计时卡片（距考试还有 X 天）
- 📊 **统计面板**：待办数、完成率、按时完成率、分类分布、最近 7 天完成趋势
- 🗑️ **回收站**：误删可恢复，保留 30 天
- ✋ **手动拖拽排序**：设置里开启后拖动卡片 ⋮⋮ 手柄插队（和自动排序互不干扰）
- 🔁 **重复任务**：完成后自动生成下一次（例会、值班神器）
- 📤 **导出/导入备份**：一键备份成 JSON 文件

### 多用户
纯前端 + 本地存储：每个人的数据只存在**自己的浏览器**里，天然互相独立、互不可见。数据层（`js/store.js`）已按"适配器"架构预留账号系统升级接口，未来换后端一行界面代码都不用改。

### PWA
可"添加到手机桌面"：有图标、全屏打开、离线可用（服务工作者缓存应用外壳）。

## 🚀 本地运行

PWA 功能（服务工作者、添加到桌面）需要 HTTP 服务，直接双击 `index.html` 只能看到界面（数据功能不受影响）。

任选其一，在项目根目录：

```bash
# 方式一：Python（Windows 一般自带）
python -m http.server 8080

# 方式二：Node
npx serve .

# 方式三：VS Code 的 Live Server 插件
```

然后手机和电脑连同一个 Wi-Fi，手机浏览器访问 `http://电脑IP:8080` 即可在手机上使用，浏览器菜单里选"添加到主屏幕"。

## 🌐 部署到 GitHub Pages

1. 把本项目推到一个 GitHub 仓库（开源说明见下）
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录
3. 等几分钟，访问 `https://你的用户名.github.io/仓库名/` 即可

## 🗂️ 项目结构

```
kitty-todo/
├── index.html          # 页面骨架（四大栏目 + 抽屉表单）
├── css/style.css       # Hello Kitty 风格样式
├── js/
│   ├── util.js         # 日期/剩余时间/颜色分档计算
│   ├── store.js        # 数据层（localStorage 适配器，预留账号升级）
│   ├── anim.js         # 勾选特效：蝴蝶结/星星/对勾/音效/震动
│   ├── calendar.js     # DDL 日历：月历 + 时间轴 + 冲突检测
│   ├── stats.js        # 统计面板（配色经 CVD 色盲安全校验）
│   ├── ui.js           # 界面渲染与交互、拖拽排序
│   └── app.js          # 启动入口、心跳、PWA 注册
├── manifest.json       # PWA 配置
├── sw.js               # 服务工作者（离线缓存；发布新版本请把 CACHE 版本号 +1）
├── icons/              # 图标（SVG + 生成的 PNG）
└── tools/
    ├── gen-icons.js    # 零依赖 PNG 图标生成脚本（node tools/gen-icons.js）
    ├── cdp-test.js     # 端到端自动化测试（node tools/cdp-test.js，需先起本地服务器）
    ├── smoke-seed.html # 冒烟测试种子页（访问后自动种入演示数据）
    └── seed.js         # 冒烟测试种子数据
```
